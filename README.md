# Mi Proyecto Web

Proyecto web simple desarrollado con **HTML y CSS** para practicar el trabajo colaborativo con **Git y GitHub**.

## Estructura
- `index.html`: página principal
- `estilos.css`: estilos de la página
- `README.md`: documentación del proyecto

## Cómo ver el proyecto
1. Clonar el repositorio: `git clone URL_DEL_REPOSITORIO`
2. Abrir `index.html` en el navegador.

## Flujo de trabajo
Cada integrante trabajó en su propia rama, hizo commits propios y luego se unieron los cambios a `main` mediante Pull Requests (merge).
